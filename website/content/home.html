Installation

npm install linkpeek

Use it on Node.js 22.12+, Bun, Deno or fetch-compatible edge runtimes. The package provides ESM and CommonJS exports with TypeScript declarations and one runtime dependency.

Usage

import { preview } from "linkpeek";

const result = await preview(
  "https://example.com/article"
);

if (result.statusCode < 400) {
  console.log(result.title);
  console.log(result.description);
  console.log(result.image);
}

Run preview() on a server or edge endpoint. Missing metadata returns null. HTTP error pages can still return metadata, so check statusCode before caching a result.

The API reference lists all options, result fields and error codes.

Parsing existing HTML

Use parseHTML(html, baseUrl) when you already have the HTML. It runs synchronously without network requests. See the Open Graph parser guide for examples and an optional interactive parser.

Presets

The default fast preset scans the document head and retains up to 30,000 decoded response-body bytes. The quality preset allows 200,000 bytes, scans body JSON-LD and image fallbacks, and can follow one validated meta-refresh.

import { preview, presets } from "linkpeek";

const result = await preview(url, presets.quality);

These limits apply to retained bytes, not total network traffic.

Security and limitations

linkpeek validates redirect targets and blocks literal private and non-global addresses by default. The runtime’s fetch resolves hostnames; public endpoints also need outbound network controls. Never forward caller credentials to arbitrary URLs. Read the security model before exposing an endpoint.

linkpeek does not execute page JavaScript, extract full articles or fetch oEmbed payloads. See troubleshooting for missing metadata and HTTP errors, or the library comparison for other use cases.
